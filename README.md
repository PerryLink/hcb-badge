# hcb-badge

> Generate an SVG badge from the canonical HCB matrix.

```bash
node scripts/badge.mjs dsh-auto-review > badge.svg
```

Badge shows compatibility (not a quality/ranking claim). Use it next to, not instead of, the ENTRY/FLOW/BOOST status.
